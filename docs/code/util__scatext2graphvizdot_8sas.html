Detailed Description

Accepts a list a scaProc (SAS Code Analyzer) generated text files, and dynamically composes the required util_parseScaproc macro call for every file in the list, before executing all the generated calls to mass convert/parse sca text to a GraphVis *.dot file

Example usage: 

%util_scaText2graphvizDot (
  p_inTxtFileList=%str(~/dotMySASProgram/output/sca_text_files.txt)
, p_outDotFilesDir=%str(~/dotMySASProgram/output/dotfiles_wo_attrs)
, p_includeAttrs_yn=N
, p_includeSteps_yn=Y
, p_rankDir=LR)
Parameters
[in]p_inTxtFileList=File name containing list of scaProc (SAS Code Analyzer) generated text file names. Required.
[in]p_outDotFilesDir=The GRAPHVIZ (*.dot) output directory. Required.
[in]p_includeAttrs_yn=A Y/N flag to include table columns in the output. Default:Y.
[in]p_includeSteps_yn=A Y/N flag to include processing steps and elapse times in the output. Default:Y.
[in]p_rankDir=Sets direction of graph layout. Valid Values:TB|BT|LR|RL. Default:TB.
[in]p_outJson_yn=A Y/N flag to also write a JSON graph (nodes/edges) next to every .dot file, named after the input file with a .json extension. Default:N.
[in]p_outDot_yn=A Y/N flag to write the *.dot files. Set to N for JSON-only output (requires p_outJson_yn=Y). Default:Y.
[in]p_dotTheme=The format of the *.dot files. Valid Values:DEFAULT|SIMPLE (see util_parseScaproc). Default:DEFAULT.
